# Repositorio Belony - Aprendizaje de Desarrollo Web

Este repositorio contiene una colección de ejercicios, ejemplos y proyectos de aprendizaje en JavaScript, Node.js, Express, React y más. Está organizado por temas y niveles para facilitar el estudio progresivo de conceptos de programación y desarrollo web.

## Estructura del Repositorio

- **Level-one/**: Ejercicios básicos de JavaScript (arrays, funciones, objetos, operadores, recursividad, etc.).
- **POO/**: Ejercicios y conceptos de Programación Orientada a Objetos.
- **React/**: Materiales y proyectos relacionados con React.
- **express/** y **Dev_Belony/Ejercicio_express/**: Aplicación Express con arquitectura en capas (controllers, services, repositories, routes, middleware). Incluye JWT, validaciones y conexión a base de datos.
- **node/**, **http/**, **sql/**: Ejercicios específicos de Node.js, HTTP y SQL.
- **html-css/**: Contenido de HTML y CSS.
- Archivos sueltos: Varios scripts de ejemplo (`async.js`, `fs.js`, `jwt`, promesas, etc.) y archivos JSON de datos.

## Dependencias principales

- axios
- dotenv
- jsonwebtoken

## Cómo usar

Explora las carpetas según el tema que quieras practicar. Cada subcarpeta o archivo contiene ejemplos autocontenidos.

## Notas

Este repositorio es principalmente para fines educativos y de práctica personal.
